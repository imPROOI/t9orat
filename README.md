## 🌟 عن المشروع

**Tasaowrat (تصوّرات)** هو تطبيق ويب تفاعلي يهدف إلى مساعدة المستخدمين على تنظيم أفكارهم واستكشاف مواضيع جديدة باستخدام الذكاء الاصطناعي (Gemini / OpenAI / Groq). 
بمجرد إدخال فكرة أو موضوع، يقوم الذكاء الاصطناعي بتوليد خريطة ذهنية متكاملة تتضمن:
- الفكرة الأساسية
- أفكار فرعية وتفريعات
- توصيات للبحث والتوسع
- مصادر مقترحة للتعلم

## ✨ المميزات الرئيسية

- 🧠 **توليد خرائط ذهنية ذكية:** بناء شجرة أفكار لا نهائية بمجرد كتابة كلمة مفتاحية.
- 📝 **ملخص ذكي (AI Summary):** تحويل الخريطة الذهنية المعقدة إلى مقال سردي متماسك باللغة العربية بضغطة زر.
- ⭐ **تمييز الأفكار (Bookmarking):** إمكانية تمييز العقد المهمة بنجمة لتسهيل الوصول إليها وتذكرها.
- 📁 **إدارة الجلسات (Sessions):** حفظ الخرائط الذهنية محلياً والعودة إليها لاحقاً (دعم حفظ وإدارة عدة جلسات).
- 📱 **متجاوب بالكامل (Responsive):** تصميم حديث وزجاجي (Glassmorphism) يدعم جميع الشاشات والأجهزة المحمولة مع إيماءات لمس محسنة.
- 🔍 **لوحة جانبية تفصيلية (Side Panel):** استعراض تفاصيل أي عقدة، سياق الفكرة، وروابط بحث مباشرة (Google, YouTube, Wikipedia, Scholar).
- 🌙 **وضع ليلي/نهاري (Dark/Light Mode):** مريح للعين مع ألوان جذابة وحركات انتقالية سلسة.
- 💾 **تصدير البيانات:** إمكانية حفظ الخريطة الذهنية كصورة (PNG) أو تصديرها كملف نصي (Markdown).

## 🌟 About The Project

**Tasaowrat** is an interactive web application designed to help users organize their thoughts and explore new topics using Artificial Intelligence (Gemini / OpenAI / Groq).
Simply enter an idea or topic, and the AI generates a comprehensive mind map that includes:
- The core concept
- Sub-ideas and branches
- Recommendations for further research
- Suggested learning resources

## ✨ Key Features

- 🧠 **Smart Mind Map Generation:** Build an infinite idea tree just by typing a keyword.
- 📝 **AI Summary:** Convert complex mind maps into a coherent narrative article with a single click.
- ⭐ **Bookmarking (Starring):** Mark important nodes with a star for easy access and memory retention.
- 📁 **Session Management:** Save your mind maps locally and return to them later (supports saving and managing multiple sessions).
- 📱 **Fully Responsive:** Modern, Glassmorphism design that supports all screens and mobile devices with optimized touch gestures.
- 🔍 **Detailed Side Panel:** Explore node details, idea context, and direct search links (Google, YouTube, Wikipedia, Scholar).
- 🌙 **Dark/Light Mode:** Eye-friendly with attractive colors and smooth transitions.
- 💾 **Data Export:** Ability to save the mind map as an image (PNG) or export it as a text file (Markdown).

## 🚀 التقنيات المستخدمة (Tech Stack)

- **React 18** + **Vite**
- **Tailwind CSS**
- **Framer Motion**
- **React Flow**
- **Google Generative AI SDK**
- **Lucide React**
- **Cloudflare Pages**

## 💻 التشغيل محلياً (Run Locally)

1. **Install dependencies (تثبيت الحزم):**
   ```bash
   npm install
   ```
2. **Start the development server (تشغيل بيئة التطوير):**
   ```bash
   npm run dev
   ```
   The app will run on `http://localhost:3000/`. When opening the app for the first time, you will be prompted to enter your API key (Gemini or OpenAI) through the settings interface.
